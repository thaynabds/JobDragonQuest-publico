JobFly

Plataforma de gestão de carreira e automação de candidaturas · Thayná Batista da Silva · versão {{VERSAO}} (novembro de 2026)

O JobFly é uma plataforma que centraliza a busca de emprego e estágio em tecnologia, no Brasil e no exterior. Quem procura vaga se candidata por muitos canais ao mesmo tempo (LinkedIn, Gupy, Greenhouse, sites de empresas, Instagram, grupos do Facebook, e-mail e indicação) e perde oportunidades e o controle dos processos. O JobFly resolve isso numa central única e explicável. A pessoa cadastra vários perfis profissionais independentes e vigia sites, ATS e redes sociais, várias fontes de uma vez e ligadas a vários perfis. As vagas dos ATS com API pública são coletadas automaticamente, e as plataformas que proíbem automação viram lembretes de conferência. Cada vaga recebe uma análise de compatibilidade com nota de 0 a 100, o motivo de cada requisito e os impedimentos eliminatórios separados da nota. Todas as candidaturas, de qualquer origem, são acompanhadas em 19 etapas atualizadas por evidência, num painel com Kanban, central de pendências e avisos configuráveis por etapa (pop-up, notificação do sistema, som e mensagem no Discord pelo Congo Grey Parrot). Uma IA pode instalar e operar o JobFly pelo servidor MCP próprio, e o painel tem português, inglês e espanhol e uma central de acessibilidade com temas, filtros para daltonismo e fonte para dislexia. O sistema nunca inventa dados do perfil, nunca trata silêncio como reprovação e respeita os termos de uso de cada plataforma.

A stack foi escolhida por maturidade, segurança e facilidade de manutenção. O back-end é uma API REST em Java 21 com Spring Boot 4.1 (Spring Security 7, Hibernate 7 e virtual threads), organizada como monólito modular, com persistência em PostgreSQL e migrações Flyway. A autenticação usa Argon2id, JWT de curta duração e refresh token rotativo com detecção de reuso, e a coleta de vagas usa um cliente HTTP restrito aos hosts dos ATS contra SSRF. O painel web é feito em React 19 com TypeScript estrito e Vite 7, e o servidor MCP em TypeScript com o SDK oficial, acessado por tokens pessoais revogáveis. A qualidade é garantida por 191 testes automatizados (JUnit 5, MockMvc e Mockito na API; Vitest e Testing Library no painel e no MCP; unittest no plugin do Congo), cobertura mínima de 80% exigida no build (93,6% medidos), integração contínua no GitHub Actions, Git Flow com Conventional Commits e versionamento semântico. O ambiente sobe localmente com um único comando.
